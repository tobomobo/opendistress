# OpenDistress 0.2.2-beta.4 — TEST prerelease

## Added

- Android companion home, saved emergency plan and settings pages. The setup
  wizard opens for initial setup and can be restarted without clearing values.
- Conversation words remain visible and editable. The callback template sets
  initial words; saved instructions remain separate from unfinished edits.
- Opaque Store icon PNGs without white or transparent corners.

## Fixed

- Garmin repeated full-profile validation could trip the watchdog. Cache the
  validated configuration and invalidate it on startup/configuration changes.
- Register the Garmin phone-message listener after application initialization
  and ignore messages missing routing keys. Physical callback validation remains
  outstanding; this is a targeted startup-crash mitigation.
- Remove overlapping Garmin readiness labels and separate provider, GPS and
  delivery status. Keep the protected clock free of alert text.

## Downloads and installation

- **Android phone:** `OpenDistress-Android-Setup-debug.apk`.
- **Pixel Watch / Wear OS:** `OpenDistress-Pixel-Watch-debug.apk`, installed on
  the watch separately. Garmin users only need the phone APK and Garmin app.
- **Garmin Store upload:** `OpenDistress-TEST-0.2.2-beta.4.iq`. Enter
  `0.2.2-beta.4` in Garmin's version field. Replace the Store image separately
  with `OpenDistress-Store-512.png` (1024px version also supplied).
- Source archive, SBOM and SHA-256 checksums accompany the installers.

Android APKs are debug-signed test builds, not Google Play releases. Android
requires the same signing certificate to update an existing installation. If a
previous CI/sideload build used a different key, an in-place update may be refused;
do not uninstall before preserving your setup, because uninstall removes local
settings. The release APKs are built locally with the existing local debug key.

## Validation and limits

- Repository CI and Android unit/lint checks; hosted native checks must pass
  on the release commit before tagging.
- Garmin: 17 native tests passed; 17 supported targets exported. The isolated
  simulator replay covers short-press cancellation, timed hold, payload building,
  simulated provider acceptance, retained state, reset and re-trigger.
- Android emulator: setup/review, saved-plan/draft separation, visible words and
  wizard restart are covered by instrumentation tests.
- No real provider alert was sent during these tests. Physical startup, latest
  hardware crash correlation, phone callback replay, GPS and haptics remain
  unverified for this build. Provider acceptance is not delivery or human help.
- External autoreview was unavailable due to source-upload approval restrictions;
  the changes received local source inspection and the recorded tests instead.

This remains TEST beta software, not a guaranteed emergency service. Apple Watch
has a native CI build/test gate but no signed installable IPA in this prerelease.
